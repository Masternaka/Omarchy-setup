# Omarchy-setup

Ce dépôt accompagne mon projet d’installation de la distribution Omarchy sur mon ordinateur à la maison.

Il servira à :

- sauvegarder et versionner mes configurations et mes dotfiles ;
- documenter mes personnalisations et les étapes nécessaires pour les reproduire ;
- développer de petits logiciels utilitaires pour faciliter l’utilisation et la gestion de mon environnement Omarchy.

Les configurations et les utilitaires seront ajoutés progressivement, selon mes besoins.

## Autorisation avant toute intervention

Le travail dans ce dépôt ne constitue pas une autorisation d’installer des logiciels ou d’appliquer des configurations à mon ordinateur. Toute installation ou modification de l’environnement de la machine doit recevoir mon autorisation explicite au préalable.

Les assistants IA doivent suivre les consignes du fichier [AGENTS.md](AGENTS.md).
